# Supplementary decision evidence

Generated by [the comparator module](../../../phase2/comparators/README.md) under its separate [protocol](../../../phase2/comparators/protocol.json). These files supplement the retained Stage 2 results rather than overwrite them.

| File | Evidence |
| --- | --- |
| `references.csv` | Exact historical rows, labels and raw ML/ordinal-grade scores |
| `candidates.csv` | Distinct reference alert sets, including canonical extreme cutoffs |
| `audits.csv` | 384 distinct method/phase/rule choices and historical selection accounting |
| `decisions.csv` | 8,252 aligned method/test-row records with saved scores, labels and frozen rule decisions |
| `evaluations.csv` | 720 method/rule/cost/cohort evaluations; phase-specific excess is summed when pooled |
| `intervals.csv` | 1,260 policy-minus-none and ML-minus-grade paired loss intervals |
| `bootstrap_counts.npz` | All 2,000 resampling count vectors per phase and pooled cohort |
| `bootstrap_replicates.npz` | All 2,520,000 paired loss differences |
| `grade_metadata.json` | Observed grade counts, source and adopted ordinal interpretation |
| `run_manifest.json` | Executed protocol/input/code/output hashes, environment, contrast definitions and elapsed time |
| `verification.json` | Actual independent enumeration, arithmetic and complete bootstrap replay scope |

Negative differences favor the left policy. Costs are hypothetical. Intervals are unadjusted and conditional on frozen policies and the current cohort, not complete training or selection uncertainty. Zero intervals for identical decisions do not establish transfer stability. See the [main report](../../../reports/overall/integrated_research_report.pdf) and [full-cost appendix](../../../reports/overall/comparator_appendix.md).
