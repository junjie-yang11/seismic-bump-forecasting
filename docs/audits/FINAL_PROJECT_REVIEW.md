## 公式与实际计算

公式是数学定义或明确的研究假设；表中数值由实际数据与模型输出代入计算，
不能将假设本身描述成实测结果。新增的 `scripts/verify_formulae.py` 不调用
被核对的指标或决策辅助函数，独立复算下列关系。

| 项目 | 核对的定义与口径 |
| --- | --- |
| AP | Σ(Recall_j − Recall_{j−1}) Precision_j；相同分数作为整体，是阶梯式平均精确率 |
| ROC-AUC | 正例分数大于负例的配对比例，加上并列配对的一半 |
| LR 先验校正 | 平衡训练先验为 0.5；p′ = pπ / [pπ + (1−p)(1−π)]；π 仅取训练标签 |
| Brier | Σ(p−y)²/N |
| Brier skill | 1 − BS_model/BS_reference；历史训练先验与回顾性测试先验基准分开 |
| ECE/MCE | 分箱概率均值与观测率之差的样本数加权均值/最大值；并列分数不拆开，所有样本归箱 |
| TreeSHAP | margin = bias + Σϕ；probability = sigmoid(margin) |
| Recall/Precision | TP/(TP+FN)、TP/(TP+FP)；零报警 Precision 的约定为 0 |
| 相对损失 | L = rFN + FP；L100 = 100L/N |
| 相对不报警 | ΔL100 = 100(FP−rTP)/N；负值表示在假设成本下损失较低 |
| 容量 | slots = floor(BN)；excess = max(0, Alerts−slots)；合并结果逐阶段求和 |
| 次优间隔 | 100(L_next−L_best)/N_ref；候选为不同可行报警集合；无第二集合时未定义 |
| 危险率情景损失 | 100[rπFNR+(1−π)FPR]；模型、阈值和经验类别内错误率冻结 |
| 情景相对不报警 | L100(π)−100rπ |
| 情景报警率 | πTPR+(1−π)FPR；这是期望报警率，不是实际容量超限概率 |
| 条件区间 | 阶段内配对移动块重采样，2,000 次、块长 32；2.5%/97.5% 分位数 |

TreeSHAP 原生输出采用 float32。独立 float64 加和与原 margin 的最大差异
为 2.4905893951654434e-6，概率最大差异为 2.1130487459775082e-7。
分别使用 5e-6、5e-7 的绝对容差，并保存真实误差；没有修改贡献或预测。

空单元格对应未定义量、无容量预算或合并结果的逐行阈值向量，不是缺少
计算而填入的替代值。+∞/−∞ 是不报警/全报警规则的规范哨兵值。
成本比、检查预算和危险率情景是预先声明的设定，不是实测经济损失。
单元测试中的构造输入仅用于测试边界，不进入实验结果或论文。
