## 已确认的冗余清理

- 删除 10 个未使用的导入名称；保留 Python 兼容性所需的 `__future__` 声明。
- 删除报告生成模块中没有调用者的 `rows`、`short`、`table`、`number` 四个辅助函数。
- 删除重复 SVG 输出的三个辅助函数及调用，保留 PNG 图形实现和诊断图。
- 删除两个未被当前论文或执行流程读取的重复 SVG 文件。
- 删除六个未使用的局部赋值，消除无用途的额外结果读取。
- 合并两份报告依赖清单，删除阶段二的重复文件。
- 清除可再生的旧 Python 缓存。

函数引用检查同时考虑导入、函数对象传递、闭包、命令行入口和测试自动发现。
仍被 baseline 生成流程调用的论文构建器、独立校验模块、模型 API 及条件分支均保留。
未把单纯的文本搜索零命中当作删除依据。62 份实验 CSV、模型文件和统计重采样
证据均保留，以便独立复算和解释非主结果。
