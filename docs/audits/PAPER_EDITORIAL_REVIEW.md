# 两阶段论文表达修订记录

日期：2026-10-03。

本轮集中修改摘要、引言、结果解释、讨论和结论，保持既定研究问题、
模型、特征、参数、阈值规则和评价公式。完整结果表、负面结果与区间解释继续保留。

## 表达调整

第一阶段以共同测试队列对验证差距解释的影响开篇，随后连接概率校准、
监测信号与预警工作量。引言集中交代研究问题；讨论明确校准改善与相对基准优势、
模型对特征的依赖与消融后的增量预测价值。案例选择仍说明其依赖预测和真实标签，
删除不影响理解的反复否定。结论回到实际证据及工程解释。

第二阶段以历史容量可行性与后续决策价值之间的关系开篇。引言明确不报警比较、
工作量转移和同阈值重训练差异；讨论将损失、TP、FN及容量超限放在一起解释。
结尾先交代回顾性记录顺序、假设成本和容量定义，再归纳阈值选择与转移分析的贡献。
未把成本情景写成实际经济损失，也未把容量超限减少自动解释为更好的检测。

## 核对方法

第一阶段报告一致性检查 8,169 项。第二阶段按锁定方案重新执行以记录更新后
第一阶段论文的来源校验值，随后回放所有固定/重训练模型与重采样值，验证
63,863 项；补充分析验证 10,902 项，独立公式验证 8,220 项。
本轮结果与润色前快照逐项比较，18 个第二阶段 CSV 和 3,960,000 个重采样值相同；
第一阶段被保护的计算证据校验值不变。两篇论文的全部表格单元内容不变。

Word、Markdown 和 PDF 核对正文及数值，检查两篇共 27 页的实际渲染，
确认图表完整、无空白页、文字遮挡或溢出。具体计数及文件校验值见
`results/phase2/editorial_verification.json` 和第二阶段 `report/report_verification.json`。
