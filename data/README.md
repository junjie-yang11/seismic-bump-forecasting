# data/

This directory is intentionally empty in the repository.

`src/data.py` downloads the dataset here on first run:

    python run_experiments.py

Source: UCI Machine Learning Repository, *seismic-bumps*
https://archive.ics.uci.edu/ml/datasets/seismic-bumps

If the automatic download fails, download this CSV manually and save it as
`data/seismic-bumps.csv`:

https://raw.githubusercontent.com/datasets/seismic-bumps/main/data/seismic-bumps.csv
